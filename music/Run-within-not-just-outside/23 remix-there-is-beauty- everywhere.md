# There is beauty everywhere  
  
Life is full, life is here,    
In each breath, in each tear,    
Run so soft, feel it near,    
There is beauty everywhere.    
  
In the rain, in the sky,    
In the moments passing by,    
Every sound, every view,    
Holds a hidden kind of truth.    
  
Don’t rush past what is real,    
There is more than what you feel,    
In the now, in the air,    
There is meaning everywhere.    
  
Life is full, life is here,    
In each breath, in each tear,    
Run so soft, feel it near,    
There is beauty everywhere.    
  
Here, here, stay a while,    
Feel the earth, feel the sky,    
Now, now, let it be,    
This is all you need to see.    
  
Life is full, life is here,    
In each breath, in each tear,    
Run so soft, feel it near,    
There is beauty everywhere.
